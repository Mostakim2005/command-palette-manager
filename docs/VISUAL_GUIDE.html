Command Palette Manager — Visual Guide

Plain-English visual map of user intent, system architecture, decisions, and landmines. Generated from docs/PRODUCT.md, docs/ARCHITECTURE.md and docs/DECISIONS_AND_TRAPS.md.

[FEATURE: Non-Destructive-Command-Snapshot] Active Feature
1-Line Summary: Records every command's factory name and icon once, so any rename or hide can be undone in a single click.

User Intention: Reverting must restore the exact original name and visibility without a vault restart, and must survive plugin reloads.

Code Anchor: src/registry.ts → CommandRegistryService.revertCommand / scanAndSyncAll
[FEATURE: Multi-Alias-Engine] Active Feature
1-Line Summary: Registers extra search words for any command as real Obsidian commands, with four selectable prefix styles.

User Intention: An alias must work from the native palette, the slash menu, and any launcher; editor-only commands must stay hidden when no editor is open.

Code Anchor: src/registry.ts → CommandRegistryService.registerAliasProxyCommand / syncAliases
[FEATURE: Safe-Command-Hiding] Active Feature
1-Line Summary: Removes commands from palettes while keeping hotkeys and programmatic execution working.

User Intention: Hiding is a view concern, never a deletion. A hidden command must still run from its hotkey, a macro, a pinned button, or another plugin.

Code Anchor: src/registry.ts → CommandRegistryService.installCommandInterceptors / hiddenBackup
[FEATURE: Raycast-Fuzzy-Quick-Palette] Active Feature
1-Line Summary: A scored fuzzy launcher with match highlighting, keyboard navigation, starring, and prefix filters.

User Intention: Two or three letters should surface the intended command; @group, #plugin, !macro and *pinned must narrow results predictably.

Code Anchor: src/quick-palette.ts → QuickCommandPaletteModal.renderResults
[FEATURE: Command-Usage-Analytics] Active Feature
1-Line Summary: Counts executions and remembers recent commands to rank the quick palette by real usage.

User Intention: Ranking reflects what the user actually runs, and the write cost never thrashes the disk.

Code Anchor: src/registry.ts → CommandRegistryService.recordCommandUsage
[FEATURE: Macro-Sequencer] Active Feature
1-Line Summary: Chains commands, inserted text, notices, clipboard writes, and URIs with per-step delays and variable expansion.

User Intention: Macros never freeze Obsidian (delays are awaited), refuse recursive self-runs, and block unsafe URI schemes.

Code Anchor: src/macro-engine.ts → MacroEngine.runMacro; src/macro-variables.ts → expandMacroVariables
[FEATURE: UI-Button-Injector] Active Feature
1-Line Summary: Pins any command or macro into five UI locations with icon, label, color, and device targeting.

User Intention: Buttons keep the user's order, never duplicate on leaf focus, and clean themselves up on unload.

Code Anchor: src/buttons.ts → ButtonInjector.syncButtons / injectHeaderButtons
[FEATURE: Action-Groups] Active Feature
1-Line Summary: Organizes commands into named groups that drive chips, filters, and the quick palette's @group operator.

User Intention: Renaming or deleting a group updates every assigned command, never orphaning them silently.

Code Anchor: src/command-manager-ui.ts → CommandManagerUI.renderGroupsTab
[FEATURE: Backup-And-Restore] Active Feature
1-Line Summary: Writes a JSON snapshot of all settings beside the plugin and can restore or import/export it.

User Intention: Restoring is explicit, confirmed, and re-applies command state immediately.

Code Anchor: src/main.ts → CommandPaletteManagerPlugin.saveBackupSnapshot / restoreFromBackupSnapshot
[FEATURE: Theme-Adaptive-Glassmorphism] Active Feature
1-Line Summary: Adapts to the active Obsidian theme with optional custom accent and frosted-glass panels.

User Intention: Contrast stays readable in light and dark themes; nothing hardcodes one color that clashes with themed accents.

Code Anchor: src/main.ts → applyThemePreferences; styles.css → .cpm-glassmorphic
[FEATURE: External-Config-Import] Active Feature
1-Line Summary: Pulls hidden commands, macros, and pinned buttons from Commander and Better Command Palette.

User Intention: Import is additive and de-duplicated; it never overwrites existing pins for the same command and location.

Code Anchor: src/registry.ts → CommandRegistryService.importExternalConfigs
[FEATURE: Inter-Plugin-Public-API] Active Feature
1-Line Summary: Lets other plugins open the manager, launch the palette, run commands and macros, and add aliases.

User Intention: These methods stay stable because other plugins call them by ID.

Code Anchor: src/main.ts → openManager / openQuickPalette / executeCommand / runMacro / addCommandAlias

[DECISION: Interceptors-Over-Command-Deletion] DECIDED BY: HUMAN
1-Line Summary: Hiding a command moves it to a backup map instead of deleting it, with wrappers keeping hotkeys and API calls alive.

Why We Pivoted: Deleting from app.commands.commands broke every bound hotkey because the hotkey manager reads that exact table. The backup map plus executeCommandById/findCommand interceptors keeps palettes clean without breaking execution.

    end

        D --> E[Re-mount for one execution]
    end
Code Anchor: src/registry.ts → installCommandInterceptors / syncOverrides
[DECISION: Context-Aware-Alias-Proxies] DECIDED BY: HUMAN
1-Line Summary: Alias commands forward checkCallback/editorCheckCallback instead of using a plain callback.

Why We Pivoted: Static callbacks made editor-only aliases appear in PDF, Canvas and Graph views, then throw when invoked. Forwarding the target's own guard hides them exactly when the target itself would be unavailable.

[DECISION: Single-Header-Actions-Container] DECIDED BY: HUMAN
1-Line Summary: Header buttons live in one reconciled container per leaf, fixing inverted order and flashing.

Why We Pivoted: Removing and prepending individual buttons reversed their order and flashed on every tab switch. One container, emptied and refilled in user order, is stable.

[DECISION: Ribbon-Item-Deregistration] DECIDED BY: HUMAN
1-Line Summary: Removing a ribbon element also removes it from the workspace's internal ribbon item list.

Why We Pivoted: el.remove() detached the DOM node but leftRibbon.items kept stale references, so repeated saves accumulated duplicate ribbon entries in memory.

Code Anchor: src/buttons.ts → clearInjectedButtons
[DECISION: Expand-Render-Limit-On-Range-Select] DECIDED BY: HUMAN
1-Line Summary: Shift-range selection raises the render limit past the last selected item so the viewport never collapses.

Why We Pivoted: Re-rendering clamped at 60 rows made items 61+ vanish while the scroll position stayed down, so the user's selection appeared to disappear.

Code Anchor: src/command-manager-ui.ts → buildCommandItem (checkbox handler)
[DECISION: Theme-Variable-Inheritance] DECIDED BY: HUMAN
1-Line Summary: Colors come from Obsidian CSS variables with an optional custom accent, replacing a hardcoded emerald palette.

Why We Pivoted: The hardcoded #00a884 broke contrast in light themes and clashed with purple, blue or red community accents. Inheriting theme variables keeps native readability.

Code Anchor: src/command-manager-ui.ts → render; styles.css → .cpm-root
[TRAP: Never-Permanently-Delete-Commands] DO NOT TOUCH
Strict Rule: NEVER remove a command permanently; stash it in hiddenBackup instead.

What Breaks If You Touch It: Obsidian's hotkey manager and other plugins read the same command table, so every bound shortcut and integration call fails until the plugin is re-enabled.

Protected Anchor: src/registry.ts → installCommandInterceptors / syncOverrides
[TRAP: Header-DOM-Recreated-On-Leaf-Focus] DO NOT TOUCH
Strict Rule: NEVER prepend individual header buttons; rebuild the single .cpm-header-actions-group container.

What Breaks If You Touch It: Obsidian recreates leaf chrome on focus; per-button injection both duplicates entries and reverses their order, and the bug looks like a styling glitch.

Protected Anchor: src/buttons.ts → injectHeaderButtons
[TRAP: Macro-Delay-Busy-Wait] DO NOT TOUCH
Strict Rule: NEVER implement a macro delay with a synchronous wait loop.

What Breaks If You Touch It: Obsidian runs on a single renderer thread; a busy-wait blocks painting and input, so the app appears hung and may be flagged unresponsive.

Protected Anchor: src/macro-engine.ts → MacroEngine.runMacro (delay handling)
[TRAP: Alias-Slug-Collisions] DO NOT TOUCH
Strict Rule: NEVER change the proxy ID scheme without handling collisions.

What Breaks If You Touch It: Proxy IDs strip everything except a-z, 0-9, _ and -, so my:alias and my-alias collapse into one command and the user silently loses an alias.

Protected Anchor: src/registry.ts → syncAliases
[TRAP: Live-Vault-Is-Read-Only] DO NOT TOUCH
Strict Rule: NEVER write to Nihon/.obsidian/plugins/**.

What Breaks If You Touch It: The live bundle is the only authoritative reference for unported behavior; mutating it destroys the reference and can break the user's daily workflow.

Protected Anchor: runtime/main.js and the mirrored vault files
[TRAP: Settings-Key-Compatibility] DO NOT TOUCH
Strict Rule: NEVER rename or restructure a DEFAULT_SETTINGS key without a migration.

What Breaks If You Touch It: Settings load through Object.assign(defaults, loaded); a renamed key silently falls back to its default, wiping aliases or pins with no warning.

Protected Anchor: src/settings.ts → DEFAULT_SETTINGS; src/main.ts → loadSettings
